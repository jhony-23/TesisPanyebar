# Manual de usuario

## Sistema digital para la administración del servicio de agua potable de la Aldea Panyebar

### Identificación del documento

- **Documento:** Manual de usuario
- **Sistema:** Sistema digital para la administración del servicio de agua potable de la Aldea Panyebar
- **Autor:** Juan Pablo Ixcamparic Escún
- **Trabajo de graduación:** Desarrollo de un sistema digital para la administración y control de pagos de servicio de agua potable mediante identificación única con código QR y plataforma web móvil para la cobranza domiciliaria en la Aldea Panyebar, San Juan La Laguna, Sololá.
- **Institución:** Universidad del Valle de Guatemala
- **Facultad:** Facultad de Ingeniería
- **Lugar y año:** Guatemala, 2026
- **Versión documental:** Estructura inicial para la documentación de usuario

### Propósito del manual

Este manual establecerá posteriormente las instrucciones necesarias para que
integrantes autorizados del Comité de Agua Potable consulten y administren la
información del servicio mediante el sistema.

En esta versión se define la estructura documental y el alcance de los temas
que deberán desarrollarse. Los procedimientos detallados, las capturas y los
pasos que requieran verificación directa de las pantallas se incorporarán en
una revisión posterior.

### Alcance

El manual cubrirá las funciones visibles del sistema para la administración
comunitaria del servicio de agua potable, incluyendo consulta de información,
gestión de registros, control de obligaciones y pagos, finanzas, jornadas,
abastecimiento, reportes, administración institucional y consulta pública
mediante código QR.

El sistema se utiliza mediante un navegador web. Este manual no describe una
aplicación móvil nativa ni funcionamiento sin conexión. Tampoco documenta
aspectos internos de desarrollo, infraestructura o configuración técnica.

### Usuarios a quienes está dirigido

El documento está dirigido principalmente a:

- integrantes autorizados del Comité de Agua Potable;
- personas encargadas de registrar y consultar información comunitaria;
- personas responsables de cuotas, obligaciones y pagos;
- personas responsables de finanzas, jornadas y abastecimiento;
- personas con funciones de administración institucional y control de acceso.

Las funciones disponibles pueden variar según los permisos asignados a cada
cuenta administrativa.

### Cómo utilizar este manual

El manual se organizará desde los conceptos básicos hacia los procesos
administrativos. Se recomienda comenzar por los capítulos de acceso,
navegación y conceptos generales, y continuar con los capítulos correspondientes
al rol y las responsabilidades de cada usuario.

Los capítulos de consulta describirán cómo localizar y revisar información. Los
capítulos de gestión describirán las operaciones de registro y actualización.
Las operaciones con consecuencias administrativas relevantes se identificarán
por separado mediante la convención de advertencia.

### Convenciones del manual

Los procedimientos se presentarán como pasos numerados cuando sea necesario
seguir una secuencia de acciones. Las siguientes convenciones acompañarán la
información del manual:

**Nota:** información complementaria útil para comprender una pantalla,
concepto o resultado.

**Importante:** información necesaria para realizar correctamente una
operación.

**Advertencia:** información reservada para operaciones con consecuencias
administrativas relevantes, como anulaciones, cancelaciones, cambios de
responsable, pagos o modificaciones de acceso.

Las capturas se identificarán mediante marcadores con el formato siguiente:

`[CAPTURA PENDIENTE CXX: descripción]`

Los marcadores se sustituirán posteriormente por capturas reales obtenidas del
sistema. No se incorporan capturas ni datos ficticios en esta versión inicial.
